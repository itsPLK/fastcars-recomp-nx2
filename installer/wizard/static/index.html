    The installer builds the game from your own discs and puts it on your console. Pick the version to install. Your extracted game files are reused between versions.

    What's new
    
  
    

    


    
  
    Before you start
    
  
    You need your own Xbox 360 discs of the game (Disc 1 and Disc 2), Title Update 27,
  a Switch 2 with kaiHEN, and about 60 GB free on this computer.
    
  
    
    
    Docker
    
    
    
    
    
    
  
    
  
    
    
    Work folder
    
    
    Everything the installer makes stays here: your extracted game files, the build, the
    shaders. Keep it to yourself: it contains the publisher's copyrighted code.
    
    
    
    
    
    
  
    
  
    

    


    
  
    Your game files
    
  
    
    
    Your game files are already extracted and checked in the work folder: the discs aren't needed again.
    
  
    
  
    
    
    Disc images (ISO) and extracted folders both work, for example a disc copied to the
    console's hard drive: there the top folder is Disc 1 and its Disc 2 folder is Disc 2.
    The files are checked against known-good hashes while they're copied.
    
    
    
      
    
    
    
      
    
    
    
      
    
      
    On the console's hard drive it's under Content/0000000000000000/545408A7/000B0000/.
    
  
    
  
    

    


    
  
    Your console
    
  
    
  
    
    
    Open OunceShell on the console. The game must be closed: FTP only answers while it isn't
    running.
    
    
    
    
    
  
    
  
    
    
    
    
    
  
    
  
    
  
    

    


    
  
    Ready
    
  
      
  
  
      

      


      
  
      Working…
      
  
      
  
      
  
      The first build takes about an hour (longer on a Mac). You can leave it running; the
  computer is kept awake.
      
  
      Details
      
  
      
  
      

      


      
  
      First start
      
  
      The console records the shaders the game needs on its first start; then they're
  translated here.
      
  
        
    
      1. Open the homebrew menu in full-memory mode: hold R while starting any game.
        2. 
    
      2. Start the game. Press A at the "No shaders yet" screen.
        3. 
    
      3. The screen stays black and you only hear the game. When it turns a little grey (a message),
      press B.
        4. 
    
      4. Wait 3–5 minutes, until you hear the game itself past the menus.
        5. 
    
      5. Quit: press HOME, then Close. Then open OunceShell again (or put the SD card back
      in this computer).
        6. 
  
      
  
      
  
      

      


      
  
      Done
      
  
      
  
        
    
      • Start the game from the homebrew menu, in full-memory mode (hold R while starting any game).
        • 
    
      • Settings while you play: press [-] and [+] together.
        • 
    
      • Saves are in switch/fastcars/data/user on the SD card: copy that folder to keep a backup.
        • 
    
      • If objects are ever missing, run the installer again and choose "Fetch shaders" at the end.
